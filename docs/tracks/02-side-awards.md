# 02 — Side awards: which we apply to and why

Special awards are open to every eligible project on top of its bounty — **except Regional and Top-Quality, which only go
to projects that win nothing else.**

| Award | Prize | Apply? | Why we fit | What we must do |
|---|---|---|---|---|
| **Best AI-Native Build** | $500 | ✅ Yes | AI advisor is a core feature (not decoration); the whole build is AI-assisted with documented prompts (`../prompts/`) | Tick "AI-native" on the project form; add `AI_USAGE.md` (what AI does in the product + how AI built it + human review); keep `prompts/` in the repo |
| **People's Choice** | $500/$300/$200 | ✅ Yes | A personal "$X exposed" result is naturally shareable; share card with #BuildBeforeQDay; public counter | Share card in app; post on X during 6–15 Dec; ask people to vote with QoreX on mainnet; **no vote manipulation** (removal risk) |
| **Regional Award** | 5×$200 | ✅ Automatic fallback | Region = team's region | Ensure profile region is set correctly; only paid if we win no other prize |
| **Top-Quality Award** | 7×$250 | ✅ Automatic fallback | Needs ≥70/100 jury + all checks passed | Same quality bar we aim for anyway; only if no other prize |
| **$50 Quantum Pass raffle** | 20×$50 | ✅ Automatic | Any passing QP project not in the top 10 | Pass every submission check |
| **Quantum Campus** | $500 | ❓ Only if every member is an enrolled student | — | Send proof of enrolment by email |
| **Q-Day Survivor** | 5×$200 | ❌ Closed | Drill ran 18 Nov, registration closed 17 Nov | — |

## Realistic stacking
- Best case: $150 (QP top 10) + $500 (AI-Native) + People's Choice place.
- If no special award: $150 only (Regional/Top-Quality excluded once we win $150).
- If we miss QP top 10: $50 raffle chance + Regional/Top-Quality chance.

## Why AI-Native is a strong bet
Few entries make AI part of the product. Ours uses it where humans struggle: turning a technical, multi-chain exposure
report into a calm, prioritised plan. And the build itself is documented as a sequence of AI prompts with validation gates —
exactly what an "AI-native build" means.
