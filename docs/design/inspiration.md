## Direction for Shor's Reach
- Dark-first "security console" aesthetic, bold display type, one strong accent (quantum violet/cyan), danger red reserved for EXPOSED_NOW.
- Big single number hero ("$X exposed"), evidence-first tables, calm copy.
- Subtle motion: scan progress lines, number count-up; respect `prefers-reduced-motion`.
- Light theme supported.
